# 中油學習卡｜阿電老師

同一個 PWA：**錯題複習**＋**學習區**（數學基礎／英文／國文／電工原理／電工機械／計時模擬考）。  
**手機與電腦都能用**（**一律底部橫向導覽**；電腦內容置中，最大約 1100–1200px，無左側欄）。

資料存在這台裝置的瀏覽器（IndexedDB），可離線使用。可下載本機 JSON，或連 **Google 雲端硬碟** 手動／排程備份。

> 完整 412 天讀書計畫仍放在 **Notion**；App 之後最多加「今天學什麼」摘要列，不會搬整份計畫進來。

## 怎麼用（GitHub Pages）

1. 把本資料夾推到 repo，開啟 GitHub Pages（根目錄或 `/docs`）。
2. 用 **Android Chrome** 打開網址 →「加到主畫面」。
3. 建議用一般模式（不要無痕），以便 IndexedDB 持久化。

本機預覽：在資料夾開靜態伺服器（例如 `python3 -m http.server`）即可。

---

## Google 雲端硬碟備份：填 Client ID

1. 到 [Google Cloud Console](https://console.cloud.google.com/) 建立專案（或沿用）。
2. 啟用 **Google Drive API**。
3. **OAuth 同意畫面**：外部／測試皆可；範圍只需 `.../auth/drive.file`（只能動 App 建立或使用者選的檔案）。
4. **憑證 → OAuth 用戶端 ID → 網頁應用程式**：
   - 已授權的 JavaScript 來源：你的 Pages 網址（如 `https://你的帳號.github.io`）與本機（如 `http://127.0.0.1:8000`）
   - 重新導向 URI：可填同一網址（GIS token 流程主要看 JS 來源）
5. 複製用戶端 ID，擇一填入：
   - 編輯 `backup-config.js` 的 `googleClientId: 'xxxxx.apps.googleusercontent.com'`（適合公開部署）
   - 或在 App **設定 → 備份** 暫時填在這台裝置（存 IndexedDB，不進 git）
6. 設定裡按「連接 Google」→ 會建立或使用資料夾「中油錯題本備份」，也可「選擇資料夾」。

**限制（請看設定頁提示）**

- Access token 只放記憶體，不存 refresh token；過期會再請你授權。
- **沒有背景上傳**：排程只在 App 開啟、回到前景、或網路恢復時檢查。
- 離線時隱藏雲端 UI，本機下載仍可用。
- Service Worker 不攔截 `accounts.google.com`／`apis.google.com`。
